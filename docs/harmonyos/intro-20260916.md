# Native particle opening — 2026-09-16

This is a requested native enhancement, not a claimed port of an upstream effect.
Inspection of pinned SuperSplat Viewer v1.31.2 (`96f62515`) found first-frame
reveal and subsequent LOD refinement in `src/viewer.ts`, but no particle-opening
implementation in its source tree.

## Behavior

OpenGL now opens a newly selected model over 1.2 seconds from its first committed
GPU selection. A position-derived stagger controls opacity and covariance size
in the vertex shader. Centers remain fixed, so the existing sort order stays
valid. No per-animation-frame CPU packing, scene upload or sort is introduced.
At completion the shader bypasses the effect entirely. The render worker returns
to its normal event-driven behavior.

`设置 → 粒子开场` enables/disables the effect; `重播粒子开场` replays it.
Changing scenes arms a new opening; later LOD commits do not restart it.
The timeline pauses on background/surface suspension. Native depth markers are
hidden during the reveal and restored afterwards. SpatialReconKit controls are
disabled because this shader extension is not implemented for that backend.

## Evidence and limits

- Host ASan/UBSan timeline regression: waiting for GPU commit, completion,
  repeated LOD commits, pause/resume, replay, cancellation and replaced request.
- Existing viewer runtime, pointer ownership and background tests pass.
- Project build and locally signed build pass.
- Installed and launched on HUAWEI Mate 80 Pro Max, SGT-AL10, API 26
  (previously recorded 7.0.0.105), display 1320×2848.
- Actual screenshots inspected: `artifacts/harmonyos/intro-phone-20260916/`:
  `public-early.jpeg`, `public-mid.jpeg`, `public-settled.png`. They show the
  public model progressively appearing and returning to the full model.
  Capture delays are approximate, not instrumented frame timings.
- Tripo and public sample switching and explicit replay exercised on phone.
- Encoded SOG shares the shader, but encoded streaming, lifecycle on device,
  2M/4M/8M performance and full parity acceptance were **not** completed here.
- No new performance claim; previous failed performance gates remain open.
