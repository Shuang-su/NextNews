# HTTP 分块流式加载（第一版）

本版本支持项目定义的 `scene.json` 清单与独立标准 SH0 PLY 块。由 Mac 解码压缩格式、按空间拆块，鸿蒙按相机位置与朝向下载并逐步替换常驻集合。**不是直接读取 SuperSplat 网页链接，也不是完整 SOG 流式解码或多层 LOD。**

## 已实现

- 网络请求、缓存写入和 Native PLY 解析异步执行；下载完一个块即可提交当前可用集合，不等待整个数据集。
- 每 500 ms 根据相机的世界位置和朝向重新选取最多 8 个块。每块上限 32,768 高斯、2 MiB；常驻高斯最大 262,144，原生合并另外守住 300,000 上限。
- 磁盘最多保留 16 个完成下载的缓存块，淘汰不在当前选集中的旧缓存；另有至多一个在途下载和短暂待淘汰块。重新连接清理旧流式缓存目录。
- 整个场景使用清单固定 center/radius，块改变时不重新计算相机归一化基准。
- 校验清单版本、字段、有限边界、数量、文件名、重复项和体积。块 URL 只拼接到清单相同目录，禁止路径穿越。HTTP 非 200、超限、长度不符和原生 PLY 解析错误均保留可见错误。
- 失败停止自动下载；可点击重试。停止后保留当前可见的 CPU 场景，并取消后续下载；可切换回内置模型。前后台暂停调度，恢复后继续。

这不是完整的细节层级算法：当前只显示被选中的块，没有为未选区域保留粗层覆盖，所以远景可能缺少区域，切换块会出现突变。没有视锥精确裁剪、屏幕误差阈值、父子层替换、过渡混合、Range 断点续传或预测预取。缓存替换采用有限集合淘汰，不宣称为严格 LRU。

原生当前重新解析并合并常驻集合，然后做全局透明排序；不是 GPU 分块增量上传。峰值内存还包括旧场景、新场景、排序副本及 GPU 缓冲，不能以磁盘缓存预算替代进程内存上限。旋转大数据仍受 CPU 排序限制。

## 本机示例

使用既有 splat-transform 解码的华发 **LOD8 诊断块 0_0**，原始文件 `.local/samples/converted.ply`，524,474 个高斯；不是完整华发项目。按最长轴中位数递归分成 32 个互不重叠的细块，无降采样，输出在 `.local/stream-huafa`。每块约 16,390 个高斯，本例 8 块约 131,000 个常驻高斯。

```bash
python3 scripts/harmonyos/prepare_stream.py .local/samples/converted.ply .local/stream-huafa
bash scripts/harmonyos/serve_stream.sh .local/stream-huafa
```

输出已存在时转换器拒绝覆盖，复现时换一个新输出目录。服务绑定 Mac `127.0.0.1:8767`，通过 HDC 反向转发供连接的模拟器访问。App：流式 → `http://127.0.0.1:8767/scene.json` → 连接流式。点击“流式”收起地址设置，或“收起工具”扩大视窗。

本轮测试服务器仍运行在本机端口 8767，便于继续试用。新启动脚本会检查端口占用，不创建重复服务。前台运行脚本可用 Ctrl+C 停止并移除其 HDC 转发；当前已运行服务器结束后，如需手动清理转发：

```bash
/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc fport rm tcp:8767 tcp:8767
```

真实部署使用 HTTPS 静态文件服务。清单地址暂不接受查询参数、片段、URL 内账号密码；不发送登录凭据。开发用明文 HTTP 只适合受信任的本地链路。输出含 SHA-256 供离线检查，本版客户端只校验长度及原生内容结构，尚未逐块验证 SHA-256。

## 格式

```json
{
  "version": 1,
  "bounds": [0, 0, 0, 10],
  "chunks": [
    {"file": "chunk-0000.ply", "count": 1000, "bytes": 56357, "bounds": [0, 0, 0, 2]}
  ]
}
```

bounds 为世界坐标中心 x/y/z 和正半径；bytes 必须与实际下载长度一致，示例数值只说明结构。最多 1,024 块，清单最大 1 MiB。PLY 子集要求见 README。

## 验证记录

- 全部 32 块的数量总和、文件长度、离线 SHA-256 与原生 ASan/UBSan 解析检查通过。
- 清单回归测试拒绝 NaN、零半径、路径穿越、重复文件、超高斯数、超体积和无效数组。
- 模拟器实际记录 HTTP GET、逐步增加常驻块、旋转相机后的新块请求；缓存到达 16 后保持预算，当前集合回到 8/8。
- 停止流式并切回本地转换样例成功。HTTP 404 与恢复重试的设备记录在 `stream-retry-test.log`。
- 证据目录：`artifacts/harmonyos/stream/`；服务请求日志 `stream-http.log`，相机调度结果 `stream/stream-results.json`。
