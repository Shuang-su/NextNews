# PLY direction-dependent color — 2026-09-17

Status: **difference** against complete MetaFlow parity. This batch implements single PLY SH1/2/3; it does not complete SOG SH, streaming SH, Huawei rendering parity or performance acceptance.

## Implementation

PLY now accepts complete float `f_rest_0…8`, `…23`, or `…44` sets, validates each value, and maps canonical channel-major properties to coefficient-major RGB. Reordered properties are supported. Incomplete sets, gaps, non-finite coefficients and unsupported degrees are rejected. Original assets are unchanged.

A separate RGBA32F texture stores unclamped DC plus 15 RGB coefficients, indexed by the same source Gaussian ID used by depth sorting. SH0 scenes allocate no SH storage. Model Rz180 is inverted for the camera-to-Gaussian direction; world camera coordinates are not rotated a second time. Polynomial evaluation comes from the pinned PlayCanvas 2.21.3 shader, used by MetaFlow. The settings menu can force SH0 for performance comparisons; diagnostics report both source and active degrees.

New SH upload shares the existing 4 MiB frame budget with base data; selection commits only when both textures are ready. Old resources remain visible until commit. Cancellation, model replacement and GL teardown release the relevant SH allocation. Memory statistics include CPU coefficients and allocated SH texture rows. The full-float layout costs 192 bytes per Gaussian on CPU and GPU, so this is not a claim of an optimized multi-million SH path.

High-order PLY in legacy chunk/page paths is explicitly rejected until selection/page storage preserves coefficients. SOG remains SH0 in this batch. No synthetic higher-order coefficients are added to missing data.
