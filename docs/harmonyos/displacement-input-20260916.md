# 飞行位移输入接续候选

接续 3021f59 的速度修复，检查发现飞行 zoom() 仍调用归一化 move，双指 pinch 仍复用环绕比例缩放，因此仍会把位移乘上场景半径。游戏控制的第二个视角触点也可能触发额外平移/缩放。

本批把飞行缩放按钮、滚轮及双指移动写入每帧一次消费的世界位移队列，与上一批速度输入共同在相机基向量内积分。取消/模式变更清空队列，避免旧事件重放。游戏控制双指不再附加位移；独立摇杆仍工作。非游戏双指平移保留按视场角/焦点距离的屏幕映射，pinch 使用官方 touch.ts 的 .4/60 世界位移系数，滚轮使用 keyboard-mouse.ts 的 .06/60；按钮保持既有因子但不再乘场景半径。环绕比例缩放未改变。

主机回归：半径 .1/1000，-120 滚轮输入前进 .12 世界单位；按钮 exp(-.2) 前进 .2；双指张开 60vp 前进 .4；一次消费、游戏双指隔离及取消清队列通过。原有 4单位/秒、相机/配置/输入归属/导航环测试通过。配套 SDK 项目及签名构建通过。
