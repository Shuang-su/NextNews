## Implemented

- Bundled SOG v2 and unbundled `meta.json` now preserve SH1/2/3 centroid textures, 16-bit labels and 256-entry SH codebooks. Validation covers finite codebooks, supported centroid width (192/512/960), height ≤1024, label bounds, image dimensions and missing components.
- The common JSON SOG downloader includes both optional SH textures, checks completion and repairs missing textures. User metadata and originals are unchanged.
- Single-model GPU rendering samples the original centroid byte codes and shared codebook. Each Gaussian carries an 8-byte label/DC-code pair, instead of a 192-byte expanded coefficient array. Shared centroid bytes and the 2 KiB codebook are uploaded once per loaded source. Allocated texture rows are included in memory statistics.
- Upload shares the existing 4 MiB frame budget, with first publication delayed until labels, centroids and books are ready. SH0/PLY and compressed SOG paths bind distinct sampler units; teardown and cancellation clear compressed resources. The SH0 comparison switch is unchanged.
- Subject/environment and legacy `chunks()` merges preserve coefficients using a bounded floating-point fallback. Reordered ranges and mixed SH0/high-order sources keep the correct coefficient identity. This fallback explicitly rejects coefficient arrays exceeding 128 MiB and retains the existing scene through the normal error path; it does not silently downgrade quality.

```sh
DEVELOPER_DIR=/Applications/Xcode-27.0.0-beta.5.app/Contents/Developer python3 scripts/harmonyos/test_sog_sh.py
python3 scripts/harmonyos/make_sog_sh_fixture.py /tmp/nextnews-sog-sh3.sog --degree 3
node scripts/harmonyos/test_cdn_cache.cjs
node scripts/harmonyos/test_stream.cjs
bash scripts/harmonyos/build.sh
```
