# 游戏控制步进修复

原问题：摇杆按 0.6 个归一化单位/秒、键盘按 1 个归一化单位/秒移动，上升/下降每次点击直接改变 0.12 个归一化单位；转到世界坐标都乘场景半径，大场景会明显跳动。按键位移还重复经过位置平滑，释放后残留目标位移。

参考本地官方 SuperSplat Viewer v1.31.2：input/devices/touch.ts、keyboard-mouse.ts 和 cameras/fly-controller.ts。默认移动速度为 4 世界单位/秒；键盘向量归一化，Shift×4、Ctrl×0.25，加速/减速 damping .992/.993；移动在相机基向量内积分。移动速度滑块作为现有用户倍率保留。

共享 OrbitControls 将世界位移换算到场景内部坐标，不再让场景大小放大速度。触控摇杆直接按帧时间积分，松开轴归零，不再二次位置平滑。键盘保留官方速度加减速。上升/下降按钮改成持有触点期间连续移动，取消、控件消失及生命周期清理归零；操作其他触点不会接管该按钮。步行原有世界单位物理步进未改。

验证：0.1、1、1000 场景半径，在 30/60/120 Hz 下满摇杆一秒均移动 4 世界单位；松手无位移尾巴；50ms 上升 0.2 世界单位；取消停止；键盘起步和减速停稳测试通过。既有输入归属、配置/相机回归及 SDK 构建、签名通过。

Mate80ProMax / SGT-AL10 / API26 / 7.0.0.105(SP10C00E105R3P3) 已安装，正式 CDN 前海冰雪世界 2M 场景长按上升、下降、摇杆前进、后退实际有连续位移，松开后摇杆回中；截图见 evidence/flight-20260916。手机保留游戏控制模式供体验。此操作验证不是 20 次性能验收；完整多指排列、硬件键盘、Web 同轨迹时序与 Huawei 仍待完成。
