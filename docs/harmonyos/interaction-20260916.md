# 标注跟随、点击目标与模型列表（2026-09-16）

本批参考官方 SuperSplat Viewer v1.31.2（96f62515）。属于交互修复，未宣称完整 Viewer 或性能门槛通过。

## 改动与原因

- 标注投影数学正确，但稳定 ForEach 键复用了非响应式位置对象。使用 @Observed 位置和 @ObjectLink 热点，在保留编号身份时更新位置及点击区域。
- 新增世界坐标点击目标环，采用官方 48 vp 直径、0.85 内径、60% 白色及 12 点平滑轮廓。导航、镜头移动时重新投影；模式切换、下一次操作等清除。原生拾取由命中高斯中心改为点击射线在命中深度处的位置，避免偏离点击像素。
- 右上角明确显示“模型列表”，直接进入线上 49 项项目列表；增大面板、修复搜索框颜色。
- 真机退出日志确认 GestureEvent.fingerList 可含空位，length>0 不保证首项存在。改为查找有限坐标并复制，不延迟引用事件；增加累计 15 vp 拖动阈值，避免拖动结束触发点击聚焦。
