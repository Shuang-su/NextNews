# 祖先像 SH3 性能回归调查（2026-09-17）

当前决策（2026-09-18）：用户决定不再使用 SH3。OpenGL 已固定 SH0，并移除方向颜色切换入口；单体、兼容合并、稳定分页均以 SH0 加载，不保留高阶系数或创建 SH3 GPU 缓冲。原文件不改写。下文为此前 SH3 调查历史，不代表当前启用状态。

## 范围与基线

用户确认“粒子开场完成时尚可，之后明显变慢”，当前复现模型为线上 **祖先像**（modelId `2092976051711868930`，单体 SOG，801,253 个高斯，源 SH3）。
接续合并提交 `3f0b66a`，仅修改 HarmonyOS。实机为 HUAWEI Mate 80 Pro Max / SGT-AL10、API 26、Maleoon 935；渲染分辨率固定 1320×2623，预算 200 万，实际数量始终 801,253。没有降低分辨率、数量或 SH 阶数来改善 SH3 测量。

用户到场时性能面板已有固定环绕 10 秒结果：53 帧 / 10.01 秒 = 5.3 fps，SH3。随后同一版本 SH0 对照为 632 帧 / 10.00 秒 = 63.2 fps。这是应用渲染完成帧计数，不是屏幕呈现或硬件 GPU 时间；面板显示 GPU 0.00 ms 的计时结果不能作为有效 GPU 耗时依据。每轮“测量 10 秒”会复位并执行同一固定环绕轨迹；并非任意手动镜头帧率对比。

此前 `0c1679c` / `a88cf59` 接通高阶 SH 并默认按源文件显示，但只有小样例正确性证据，未通过大单体性能验证。不能把新增方向颜色后的速度直接等同于原 SH0 基线，也不能将当前回归归罪于粒子开场。开场已经结束、后处理关闭的 SH3 仍然很慢。

## 实现

- 单体及兼容合并路径增加 GPU 颜色工作缓冲，每个源高斯计算一次 SH，四边形四个顶点复用结果。颜色按源索引存储，排序只改变绘制索引。
- 缓存键包括源 Scene 身份、相机世界位置、所选阶数；静止镜头及仅排序变化不重算。换场景、阶数变化、窗口重建分别失效或释放。仍保留直接计算回退；稳定分页流式不宣称已经使用工作缓冲。
- 单体 SOG 只将共享质心表解码为精确 float32，保留每个高斯的标签；不展开数百万份 SH 系数。上传按解码后真实字节继续遵守 4 MiB 批次预算。
- SH 系数逐项累加，避免动态索引的大型局部数组。SOG 预计算与已缓存颜色的绘制分别编译专用程序。
- 直接着色回退在透明度、裁剪面和视锥裁剪后计算方向颜色。揭示期间依然使用原始高斯位置求颜色，不改变模型或镜头坐标语义。
- 新增显存计入性能面板。实验中的同步 `glFinish` 探针已移除，正式路径没有 GPU 强制同步。

参考：本机 MetaFlow 对应 PlayCanvas 2.21.3 的 `gsplatCopyToWorkbuffer`、`formats/sogSH`；采用其“预计算后复用”流程，并针对该手机对存储方式实测选择。并非整个 SuperSplat 渲染架构已经移植完成。

## 中间实验（非最终验收）

| 版本 | SH3 固定轨迹结果 | 说明 |
|---|---:|---|
| 合并版本 | 5.3 fps | 到场时用户测量 |
| 共享表解码 + 裁剪后计算 | 7.9 fps | 仍每顶点重复 |
| 展开读取 | 8.7 fps | 局部优化不足 |
| GPU 工作缓冲初版 | 13.7 fps | 每高斯一次 |
| 专用绘制 + float32 共享表 | 18.0 / 18.1 / 17.8 fps | 三次重复；整数颜色附件 |
| 压缩码本工作缓冲 | 11.5 fps | 在此手机更慢，未保留 |

整数颜色附件候选的 SH0 回归为 63.3 fps；模型缓冲估算由 114.5 增至 138.0 MiB，额外开销来自共享浮点表和每高斯颜色缓冲。不是进程总内存或峰值。

## 验证与限制

- 配套工具链构建 HAP、实机安装启动成功。
- `test_sh_gpu.py`：2,910 个独立谐波参考对照样本，包含 SH1/2/3、float / compressed / paged、不同标签、相机方向、世界变换、不同高斯地址。最坏绝对误差约 `1.52e-7`。
- `test_sh_workbuffer.py`：实际生产上传及工作缓冲类，覆盖浮点/SOG、不同高斯系数、镜头位置变化、未变镜头复用、SH0 旁路和资源重建。Mac GPU 结果只证明该平台测试，不代替手机视觉证据。
- `test_core.py`：解析、数学、异常输入，ASan + UBSan 通过。
- 证据保存在 `evidence/ancestor-sh-20260917/`。
- 仍需进一步优化 SH3 工作缓冲和绘制成本；不能宣称已恢复约 60 fps，或与手机 Web Viewer 完全持平。
- 稳定分页 SH3、400/800 万档和 20 次完整缓存性能门槛未在本批重验。华为原生未改动。
