# MetaFlow 手柄双摇杆接续

参考 MetaFlow `a871786dffdb195399f3e7427987d8db70296491` 的
`src/input/devices/gamepad.ts` 与 PlayCanvas 2.21.3 `GamepadSource`。
此固定版本只使用双摇杆，读取原始标准轴，没有应用层死区或按键动作。

- 接入 SDK API 21+ 的 GameControllerKit 左/右摇杆监听，通过线程安全快照供共用控制层读取。
- 左杆移动 4 世界单位/秒，右杆 18 度/秒，第一人称乘 FOV/120。
  环绕采用相机距离乘平移量和相对缩放；步行经过既有碰撞模块。
- 人工输入中断动画和点击导航。菜单打开时暂停手柄导航。
- 前后台、页面隐藏、离开及设备连接变化清零，取消订阅。
- 注册失败禁用手柄输入，不影响触摸、鼠标及键盘。

构建、轴数学/帧率/FOV 测试通过，既有多触点和输入回归通过。
**没有连接物理手柄，真实轴方向、断连、不同型号、双后端轨迹尚未验收。**
当前记录最后收到的双摇杆，未复刻 Web 多手柄轴求和；此项保持“差异”。
菜单暂停输入是移动端明确隔离策略，不能称为已完成逐项官方输入对照。

同时修复资源缓存临时文件复用：并发场景请求使用独立临时文件，完整写入后原子发布，
取消/失败删除自身临时副本。并发写入测试确认最终文件完整、无混合内容和残余临时文件。

## 2026-09-17 follow-up

Device monitoring now registers before thumbstick monitors, as required by the installed official guide `game-controller-monitor-pad`. Axis state is keyed by device ID; disconnect/reconnect clears only that device. Axis values are validated/clamped per device, then summed without a second clamp, following pinned PlayCanvas `GamepadSource`. Background/disable clears all devices. Returned ID strings and device-info objects are released after copying.

Native ASan/UBSan tests cover two-device sums, independent left/right axes, removal, reconnect state, non-finite input and lifecycle clearing; ArkTS movement math and paired SDK build passed. No physical gamepad is attached, so actual axis mapping, device callbacks and disconnect behavior remain blocked for hardware acceptance.
